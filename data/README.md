# Input data location (local only)

Keep source SPAM CSVs and project-specific evidence/reference datasets in this local `data/` folder following [`../docs/inputs.md`](../docs/inputs.md) and [`../docs/data-sources.md`](../docs/data-sources.md).

The GitHub ZIP does **not** include these files. The full manifest is [`../tools/SPAM-required-files.csv`](../tools/SPAM-required-files.csv). The `.gitignore` intentionally prevents accidental commits of the populated `data/` folder, except this README. Source licences and rights-holder permissions apply separately.
