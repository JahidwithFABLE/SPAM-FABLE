# Expected local data paths

This repository uses a single `--data-root` and does **not** hard-code a developer's Windows path. The public code ZIP does not contain the source/evidence/reference data.

```text
data/
├── SPAM/
│   ├── CSV/2000/                   # 2 source CSVs
│   ├── CSV/2005/                   # 6 source CSVs
│   ├── CSV/2010/                   # 6 source CSVs
│   ├── CSV/2020/                   # 6 source CSVs
│   └── _07B_required_extracted/2005/cell5m_allockey_xy.csv
├── mapping_audit/                  # 5 frozen mapping/source evidence files
├── legacy/06_harmonized_irrigation/ # two approved MIRCA evidence files
└── SPAM_FABLE_FINAL/               # saved mapping, completion, grids, crosswalk,
                                   # candidate reference, QC and metadata
```

All **52 exact relative paths** are listed in [`../tools/SPAM-required-files.csv`](../tools/SPAM-required-files.csv). These include 21 original source/lookup files and 31 additional evidence/reference files. The directory names and nested original filenames are significant.

See [`data-sources.md`](data-sources.md) for the authoritative links and honest public availability, and [`copy-inputs.md`](copy-inputs.md) for check/copy commands. A third party cannot execute the full six-stage v1.0.0 pipeline with only public raw SPAM inputs; frozen project evidence/reference data are additionally required and not supplied here.

`runs/` is generated by scripts, not an input directory; output datasets are never directly written into the canonical reference tree. The validated runner supports `--data-root` and separate `--run-root` configuration.
